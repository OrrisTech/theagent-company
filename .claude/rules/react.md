# React Conventions

- React 19 + TypeScript + Vite + Tailwind CSS + Radix UI
- State: TanStack Query for server state, zustand for client state
- Pages: `ui/src/pages/`
- i18n: i18next + react-i18next; all user-facing strings must have `en` + `zh` keys
- UI must be responsive (desktop + tablet viewports)
- No console errors or warnings in dev tools
- Follow existing Paperclip code style and patterns
